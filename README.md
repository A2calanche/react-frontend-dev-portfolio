<h3>:books: Getting started</h3>

> ⚠️ This repo is a fork — not an original template. If you're looking for the base template to customize yourself, head over to [Dorota1997/react-frontend-dev-portfolio](https://github.com/Dorota1997/react-frontend-dev-portfolio).

If you still want to fork this version:

1. Clone or fork the project.
2. Install required dependencies with `yarn install`.
3. Add the `homepage` on `package.json`:

```json
{
  "name": "react-frontend-dev-portfolio",
  "homepage": "https://YourGithub.github.io/react-frontend-dev-portfolio/",
  "version": "0.1.0",
  ...
}
```

4. Run `yarn start` and customize it.
5. Deploy with `yarn deploy`.

> **Note:** If you want to run it locally with `npm run start`, make sure you've edited the `homepage` property or the JSON data won't load.
